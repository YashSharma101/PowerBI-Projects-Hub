# 📱 Mobile Sales Dashboard | Power BI

An interactive **Power BI dashboard** designed to analyze mobile sales performance and generate actionable business insights.

### 📊 Key Analysis

* Total Sales, Quantity & Transactions
* Monthly and day-wise sales trends
* Brand and mobile model performance
* City-wise sales analysis
* Payment method distribution
* Customer ratings and purchasing patterns

### 🛠️ Tools Used

**Power BI | Power Query | DAX**

### 🎯 Objective

To transform raw mobile sales data into an **interactive, data-driven dashboard** that helps identify sales trends, top-performing products, customer preferences, and regional opportunities.
